# Project Context

Before implementing anything:

1. Read the project documentation.

2. Understand the current sprint.

3. Understand completed features.

4. Understand pending features.

5. Never duplicate existing functionality.

6. Never introduce architecture that conflicts with previous decisions.

7. Keep an internal mental model of:

- Database
- APIs
- Frontend
- Backend
- Folder structure
- Design system
- Business rules

Always assume future conversations continue from previous work.
